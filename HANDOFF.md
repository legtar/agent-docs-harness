## Что можно делать дальше

Это возможные расширения, а не обещанные или начатые задачи:

1. При новых пользовательских документах: сохранить оригинал, воспроизвести дефект на копии, добавить регрессию, исправить, выполнить общий gate и визуальный QA.

4. При установленном Microsoft Word можно добавить проверку различий его рендера с LibreOffice. Сейчас эталон — LibreOffice/PDF.

## Как продолжать безопасно

- Ничего не создавать в OneDrive. Все правки выполнять в указанной локальной папке; shell cwd сессии может указывать на OneDrive, поэтому задавай абсолютный workdir.
- Оригиналы не перезаписывать. Не генерировать и не проверять через LibreOffice один и тот же выходной DOCX одновременно: Windows может блокировать публикацию.
- После изменений tools/templates: python tests/validate.py --offline; для новых документов: qa.py, затем просмотреть sheet.png и все дополнительные листы.
- Python: C:\Users\aleks\AppData\Local\Programs\Python\Python312\python.exe; PYTHONUTF8=1. LibreOffice: C:\Program Files\LibreOffice.
- В этой сессии exec_command зависал; использовали Node REPL и child_process с явным cwd и переменными LOCALAPPDATA/APPDATA/USERPROFILE/SystemRoot/TEMP/TMP/PATH. Долгие процессы выводили в файл через spawn, чтобы пережить таймаут REPL. Это наблюдение среды, не обязательный способ запуска.
